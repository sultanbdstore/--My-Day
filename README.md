# আমার দিন · My Day
Bangla & English to-do list, habit tracker, daily streaks and prayer times. Works offline, installable, no account, no server. Data stays on your phone.

**Features**
- 📅 Calendar tab (Gregorian month view, week starts Saturday by default, full weekday names such as শনিবার / Saturday, day detail with prayers, habits and tasks), week strip on the Today screen, relative due dates, large-text option
- ✅ Tasks with priority, due date and time; Today / Upcoming / All / Done
- 🔥 Habits with weekday schedule, current and best streak, 7-day strip, 30-day grid, quick templates (Quran, water, exercise, Tahajjud, Mon & Thu fasting...)
- 🏠 Today screen: progress ring, day streak, next prayer countdown, daily reminder quote
- 🕌 Prayer times calculated offline (Karachi 18°/18°, Hanafi Asr) for 20 Bangladeshi cities or GPS, minute adjustments, Qibla bearing, tick each prayer, pause day
- 🔔 Notifications while the app is open, plus a calendar file (.ics) so the phone alerts you even when the app is closed
- 📊 Weekly chart, perfect days, backup / restore, Hijri date, light / dark theme, Bangla / English

## Publish on GitHub Pages
Upload all files to a repo, then Settings → Pages → Source: **Deploy from a branch** → `main` → `/ (root)` → Save.
After editing `index.html`, change `VERSION` in `sw.js`.

## Honest notes
- Browsers cannot ring alarms when an app is closed; use "Add reminders to calendar" for reliable alerts.
- Check prayer times against your local mosque and use the minute adjustment if needed.
- Data is stored in the browser. Clearing browser data erases it, so back up regularly.
